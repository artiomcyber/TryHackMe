# TryHackMe Cybersecurity Labs

Hands-on cybersecurity learning, labs, and projects completed through **TryHackMe**, with selected exercises recreated and documented in dedicated lab environments.

This repository documents practical work across:

- Identity & Access Management (IAM)
- Microsoft Entra ID
- Microsoft security
- SOC / Blue Team operations
- SIEM and log analysis
- Networking
- Windows and Linux
- Active Directory
- Phishing analysis
- Defensive security
- Security fundamentals

The goal of the TryHackMe account is mainly hands-on practice in Cybersecurity, troubleshooting failures, and documenting the results.
