# TryHackMe Microsoft Entra ID

Hands-on Microsoft Entra ID learning and lab documentation based on the **TryHackMe Microsoft Entra ID module**.

The module focuses on practical identity and access management in modern Microsoft environments, including identity lifecycle, hybrid and external identities, authentication, Zero Trust, Identity Protection, privileged access, and governance.

When the TryHackMe cloud tenant is unavailable, I recreate the hands-on exercises in my own dedicated Microsoft Entra lab tenant using fictional identities and least-privilege administrative roles.
